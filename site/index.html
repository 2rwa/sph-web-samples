SPH Web Samples

Small browser experiments for SPH implementations.

  • Salva 2D → Rust/WASM → Canvas — 216 particles rendered as simple Canvas dots.
  • Salva 2D WASM benchmark — adjustable from 100 to 10,000 particles.
  • Salva interactive obstacles — draw Circle, Box, Line, and Free Draw boundaries into a 1,000-particle SPH scene.
