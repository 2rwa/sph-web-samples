Faucet → Salva/WASM → WebGPU atomic splat raymarch

The Salva faucet continuously emits particles. WebGPU splats each particle only into nearby voxels using fixed-point atomic density accumulation, converts that buffer into a 40×96×40 density grid, then raymarches it as a continuous liquid surface.

Density accumulation uses atomic<u32> fixed-point values instead of float atomics. The density field is not an SDF, so rendering uses fixed ray steps plus binary hit refinement.
